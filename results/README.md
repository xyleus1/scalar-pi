# Completed observed study

`study-v0.1.0.json` contains the 80 suite-cell and 800 task summaries, 20
checkpoint/K macro averages, and eight original paired-bootstrap contrasts.
Differences and confidence intervals are success-probability fractions; multiply
by 100 for percentage points. These are descriptive mixed-hardware results.
The study filename identifies the original results and stays fixed across paper revisions.

The [latest paper release](https://github.com/xyleus1/scalar-pi/releases/latest)
contains the PDF and editable source. The curated 40,000-episode dataset remains
at [v0.1.1](https://github.com/xyleus1/scalar-pi/releases/download/v0.1.1/scalar-pi-data.zip);
later paper revisions reuse it without changes. Large logs, training data and
checkpoints are not stored in this Git tree. See the [paper guide](../paper/README.md)
for GPU-free reproduction and [research license](../LICENSE-RESEARCH) for CC BY 4.0
attribution. Public release files have their own checksums; their sanitization
does not alter private original evidence.
