# Completed observed study

`study-v0.1.0.json` contains the 80 suite-cell and 800 task summaries, 20
checkpoint/K macro averages, and eight original paired-bootstrap contrasts.
Differences and confidence intervals are success-probability fractions; multiply
by 100 for percentage points. These are descriptive mixed-hardware results.

The versioned release contains the paper PDF, editable sources and curated
40,000-episode dataset. Large logs, training data and checkpoints are not stored
in this Git tree. See `../paper/README.md` for GPU-free reproduction and
`../LICENSE-RESEARCH` for CC BY 4.0 attribution. Public release files have their
own checksums; their sanitization does not alter private original evidence.
